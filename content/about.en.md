Hi. I'm **Umut Can AKÇAY**, a computer engineering student and full-stack developer based in İstanbul. I'm interested in building the web end to end and in understanding how the systems underneath it actually work.

On this blog I write about software engineering, mathematics, and long-form thinking. The goal is to accumulate notes that keep their value over time, rather than content meant to be consumed quickly.

## What I work with

- **Languages:** JavaScript/TypeScript, Python, C, C++, Java, Bash, SQL
- **Backend:** Node.js/Express, NestJS, Flask, .NET MVC Core, REST APIs, WebSockets (Socket.IO)
- **Frontend:** React, Next.js, Vue, Tailwind CSS, Bootstrap
- **Data & ML:** pandas, NumPy, scikit-learn, LightGBM/XGBoost, embeddings and vector search (RAG), LangChain, LLM tool-calling
- **Systems:** Linux, Docker, WebRTC, P2P/DHT, parallel computing
- **Spoken:** Turkish (native), English (B2), German (A1)

## Featured projects

- **[peercomp](https://github.com/HyoAkira/peercomp)** — serverless JavaScript on a Kademlia DHT over WebRTC: browser tabs become compute nodes, sandboxed and signed, with no cloud dependency.
- **[sessionflow](https://github.com/HyoAkira/sessionflow)** — self-hosted, privacy-friendly web analytics: a tracking snippet feeds an Express/Socket.IO + MongoDB backend, a React dashboard shows the traffic, and a Flask service runs scikit-learn analysis.
- **[threat-aggregation-intelligence-platform](https://github.com/HyoAkira/threat-aggregation-intelligence-platform)** — threat-intelligence IOC aggregation: normalizes ThreatFox and PhishTank feeds, deduplicates them, and serves search, MCP tools, and AI-written reports.
- **[local-rag-ingest](https://github.com/HyoAkira/local-rag-ingest)** — local-first toolkit for a D&D 5e game master: campaign notes into a Qdrant vector store with Ollama embeddings, game state in SQLite; action data prepared for a local llama.cpp model. The tool-calling engine that consumes them is **in progress**.
- **[web-recon-scanner](https://github.com/HyoAkira/web-recon-scanner)** — passive web attack-surface scanner with a Streamlit UI: DNS, TLS and header checks, certificate-transparency subdomains, gau/theHarvester/whatweb.
- **[lean-mcp](https://github.com/HyoAkira/lean-mcp)** — an MCP server that compiles Lean 4 locally with the real toolchain and returns structured compiler diagnostics, so coding assistants can verify proofs (GPL-3.0).
